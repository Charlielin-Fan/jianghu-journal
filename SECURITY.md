# Security

江湖行记 stores schedules locally and does not require an account. Its runtime web server binds to <code>127.0.0.1</code> and is used by the local desktop window or browser tab.

If you find a security issue, please use GitHub's **Report a vulnerability** option for this repository when available. Do not include <code>数据/行记.json</code>, backups, or private screenshots in a report. Use synthetic data when describing a reproduction.
